MyLatex — User Guide

A fast, private LaTeX editor for Mac. Write on the left, see your PDF on the right. Everything runs on your computer: no account, no TeX installation, no upload.

Installing & first launch

Open the MyLatex.dmg disk image and drag MyLatex onto Applications. If macOS says the app “can’t be opened because the developer cannot be verified” (this happens with builds that are not notarized by Apple), right-click MyLatex → Open → Open once; or go to System Settings → Privacy & Security and click Open Anyway. You only need to do this the first time.

Quick start

  1. Press ⌘N for a new document (it starts with a small template), File → New from Template for a paper, slides, CV or letter, or ⌘O to open a .tex file. You can also drag a .tex file onto the window.
  2. Type. With Autocompile on (default) the PDF refreshes shortly after you stop typing. Otherwise press ⌘↵ or the Compile button.
  3. Save with ⌘S. Get the PDF with the PDF button above the preview (or ⇧⌘E).
First compile ever? MyLatex ships with the LaTeX format and the most common packages, so it works offline right away. Rarely used packages are downloaded once, on request, and then kept.

Files & projects

  • MyLatex never writes to your files behind your back — unless you turn on Auto-save. Compiling uses the text in the editor; the file on disk only changes when you save (⌘S) or when Auto-save is on. The one exception: when you edit a file that belongs to a project (see below), it is saved before compiling so that \input sees your change.
  • ⌘S save · ⇧⌘S Save As · ⌥⌘S Save All · ⌘W close tab. Closing or quitting with unsaved changes asks what to do.
  • Auto-save (off by default): flip the Auto-save switch in the top bar, or use File → Auto-Save. When it is on, every file that already has a name is saved about a second after you stop typing, when you switch tabs or leave the window, and when you quit. Untitled documents are never auto-saved — save them once with ⌘S to give them a name.
  • Crash-proof: open tabs and unsaved text are restored the next time you launch MyLatex.
  • In Finder, use Open With → MyLatex on a .tex file, or drag it onto the MyLatex icon.

Projects with several files

Open the main file (the one with \documentclass). Everything in the same folder — .sty, .cls, .bst, .bib, images, \input-ed sections — is found automatically, and BibTeX runs by itself.

To edit a section file and still get the whole document in the preview:

  • Open the main file, then use Build → Set as Main Document (⇧⌘M). Compiling from any file in that folder now builds the main document. Run it again to clear.
  • Or put % !TEX root = main.tex at the top of the section file (the main file must be open).

Templates

File → New from Template opens a ready-to-compile document in a new tab: Article, ICML-style paper, NeurIPS-style paper, IEEE conference paper (uses the real IEEEtran class), Beamer presentation, CV / Résumé (uses moderncv) and Letter. The ICML and NeurIPS templates are look-alikes built on standard packages (two columns / single column, Times, the usual section layout): the official .sty files are not bundled because they are issued per conference year. To submit, put the official .sty next to your file and uncomment the \usepackage line shown at the top of the template.

Images

Drop a PNG, JPG or PDF onto the window (or use Image in the toolbar). MyLatex copies it into a figures/ folder next to your document if it lives elsewhere, adds \usepackage{graphicx} if needed, and inserts a figure with \includegraphics, \caption{} and \label{}. Save an untitled document first so the path can be relative.

Bibliography

Add \bibliography{refs} (BibTeX) or \addbibresource{refs.bib} (biblatex) and keep the .bib next to your .tex. Type \cite{ to pick keys from it.

Compiling

  • Autocompile — flip the Autocompile switch in the top bar (or Build → Auto-Compile While Typing). When on, the PDF refreshes shortly after you stop typing; turning it on compiles immediately. ⌘↵ or the Compile button compiles at any time.
  • While packages are being downloaded, a thin bar under the tabs and an overlay at the bottom of the preview show real progress: percentage, files, megabytes. Normal compiles show no animation at all — just the status text.
  • Offline first. Compiling uses only what is already on your Mac. If something is missing, MyLatex shows a “Download needed” card instead of silently going online. Click Download and compile to fetch it (internet required); it is then kept.
  • Keep Downloaded Packages After Quit (Build menu): when off, downloaded packages are cleaned when you quit, and the built-in starter set is restored on the next launch.

Errors & warnings

  • On error, a panel lists each message with its line and the offending code. Click an entry to jump to that line (even in another file). Full log shows the raw output; Esc closes the panel.
  • Lines with errors are underlined in red in the editor (hover for the message); lines with warnings get an amber dotted underline.
  • The status shows the warning count (“compiled · 3 warnings”). Click it to list them.
  • File not found for your own .sty/image? The card offers Add file to project…, which copies it next to your document.

PDF viewer

  • Zoom: the − / + buttons, ⌘ + scroll, or pinch on the trackpad. It follows your cursor and sharpens a moment after you stop. Click the percentage to reset to 100 %.
  • Pages: the bar shows the current page and total; use ‹ › to move.
  • PDF button: saves the compiled PDF where you choose (also ⇧⌘E). File → Save .tex and PDF Together writes both next to each other.
  • Editor → PDF (find a word in the PDF): put the cursor on a word (or select a phrase) and click Show in PDF above the preview, press ⌘J, or ⌘-click the word in the editor. The PDF scrolls there and flashes a yellow highlight. If the same word appears several times in the paragraph, MyLatex picks the one that matches your position; if it can’t be located from the source line, it searches the whole PDF (press again for the next match).
  • PDF → source: double-click (or ⌘-click) a word in the PDF to jump to its line in the editor and select the word.

Editing aids

Autocomplete

Suggestions pop up as you type; ↑↓ to choose, Enter or Tab to accept, Esc to dismiss, Tab again to move between blanks in a template.

  • Commands: type \fr → \frac{}{}, Greek letters, operators, layout commands…
  • Environments: \begin{equ → full \begin{equation}…\end{equation} with the cursor inside.
  • \cite{ lists the keys of your .bib files with titles. \ref{, \eqref{, \cref{ list your \labels.
  • Packages & classes: after \usepackage{ and \documentclass{.

Brackets and lines

  • Auto-close: typing {, [, ( or $ inserts the closing one and puts the cursor between; typing the closing character steps over it. Type \begin{itemize} and the } adds the indented body and the matching \end{itemize} automatically. (Turn this off in Preferences.)
  • Move line ⌥↑ / ⌥↓ moves the current line (or all selected lines); Duplicate line ⇧⌥↓ copies it just below.

Formatting shortcuts

⌘B bold, ⌘I italic, ⌘U underline wrap the selection (or insert an empty pair with the cursor inside). Press again to remove. ⌘/ comments or uncomments lines.

Search

⌘F find & replace · ⌘G / ⇧⌘G next/previous · ⌘L go to line. Double-click a word to select it; other occurrences are highlighted.

Visual mode

Click Visual (or ⌥⌘V). The text stays editable LaTeX, but markup is tidied up like in Overleaf:

  • Titles and sections appear as headings; \textbf, \emph, \texttt… are rendered; \item becomes a bullet.
  • Math is typeset ($…$, \[…\], equation, align…), including your own \newcommand macros. \cite / \ref become small chips.
  • Place the cursor on any element to see and edit its raw LaTeX.
  • Tables, figures, algorithms and other environments stay as code in this mode.

Spell check (English & French)

Misspelled words are underlined with a red wavy line as you type. MyLatex has two built-in dictionaries: English (about 115,000 words — American and British spellings plus common scientific and computing vocabulary) and French (about 330,000 forms, accents and elisions such as l’homme, qu’il included). Nothing is sent anywhere. Only the text on screen is checked and a dictionary is loaded only when it is needed, so memory use stays tiny.

  • Language: automatic or manual. The selector next to the Spelling switch (toolbar) is on Auto by default: MyLatex looks at \usepackage[french]{babel} (or polyglossia, \selectlanguage…) and, when there is none, at the most common words of your text. The detected language is shown at the right of the bottom bar. Pick English or Français in the selector (or in Edit → Spelling Language, or Preferences) to force one.
  • Switch it on/off with the Spelling switch or Edit → Check Spelling While Typing.
  • Right-click an underlined word for suggestions: click one to replace the word, or choose Add to dictionary (remembered forever; manage the list in Preferences) or Ignore for this session. Edit → Add Word at Cursor to Dictionary does the same from the keyboard.
  • Not checked (so you won’t see false alarms): LaTeX commands and their arguments, math, comments, URLs and e-mail addresses, the preamble, words with digits, ACRONYMS, CamelCase names, and capitalized words in the middle of a sentence (assumed to be names). In English, contractions and accented words are skipped too.
  • Proper names and very specialised terms may be underlined once — add them to the dictionary and they are never flagged again.

Preferences & language

MyLatex → Preferences… (⌘,) gathers every setting in one window: interface language, theme, font size, tab width, line wrapping, font ligatures, auto-close of brackets, compile/save switches, spell-check language, your personal dictionary, and a reset button.

Changing the language of the interface (menus, buttons, messages and this guide) takes one click: View → Language or the Language row of Preferences. MyLatex ships in English, Français, Español and Deutsch and starts in your Mac’s language. (The guide is available in English and French; other languages show the English guide.) Adding another language only takes one translation column — see the tools/build-lang.py file in the source.

Themes

View → Theme: Match System, Light, Light with Light Header, IntelliJ Light, Islands Light, Fleet Light, Dark, Darcula, Islands Dark, Fleet Dark, High Contrast. ⇧⌘D flips between light and dark. ⌘= / ⌘- / ⌘0 change the editor font size.

Tips & typical workflows

Writing a paper

  1. Open the template’s main file, set it as the main document (⇧⌘M), keep the outline open to move between sections.
  2. Write with Visual mode on for prose; switch to Code for tables and figures.
  3. Use ;eq / ;fig / ;tab snippets, \cite{ completion for references, and Show in PDF (⌘J) to check where a paragraph landed.
  4. Turn Auto-save on so you never lose work, and export with the PDF button when you are done.

Reviewing a PDF

Double-click any word in the preview to land on its source line — handy when a reviewer says “page 4, second paragraph”.

Working offline

Everything works without internet except downloading a missing package. Before a trip, compile your document once while online so everything it needs is cached (leave Keep Downloaded Packages on).

Several windows of work

MyLatex is a single window with tabs. Open all the files of a project as tabs; the ◆ tab is the one that is built.

Conference templates (ICML, IEEE, NeurIPS, beamer…)

  1. Unzip the template into a folder and open its main .tex file in MyLatex.
  2. Keep the template’s .sty, .cls, .bst, .bib and figures in that folder.
  3. Compile. BibTeX/biblatex runs automatically. If a template needs a package that is not in the offline cache you will get the Download needed card.
  4. For a multi-file template, open the other files in tabs and set the main document (⇧⌘M).

Troubleshooting

“Download needed”A package or font isn’t in the local cache. Click Download and compile once; it’s then kept.
“File … not found”The file isn’t in the TeX distribution either — it’s probably your own. Put it next to the .tex (the card has an Add file to project… button).
The preview is emptyLook at the status: if it says “error”, click it. Otherwise press ⌘↵.
Citations show “?”Check \bibliography{…} / \addbibresource{…} points to a .bib in the project folder, and compile once more.
Table of contents / references show “??”Compile again; MyLatex re-runs LaTeX automatically but a new label needs one extra pass.
My changes aren’t on diskA blue dot on the tab means unsaved. Press ⌘S, or turn Auto-save on. Untitled documents need a first ⌘S to get a name.
Autocomplete shows no citationsMake sure the document declares its bibliography (\bibliography{refs} or \addbibresource{refs.bib}) and that file is in the project folder. Switch tabs or compile once to refresh.
Visual mode shows raw codeThat’s intentional near your cursor: the element you are editing is shown as source. Move the cursor away to see it formatted. Tables and figures always stay as code.
“Show in PDF” highlights the wrong spotCompile first so the PDF matches your text. If the word is inside a formula or split across lines, MyLatex highlights the whole paragraph instead.
The window opened on another screenDrag it by its title bar, or use Window → Zoom.
Where are my files?Exactly where you saved them. MyLatex keeps only temporary build files, deleted on quit.
Memory useMyLatex draws only the pages near the screen and frees the PDF engine when idle. Close tabs you don’t need and keep Visual mode off for very large documents.
Reset to defaultsQuit MyLatex, then delete ~/Library/WebKit/app.mylatex.desktop (settings and the saved session).

Privacy

Your documents never leave your Mac. The only network access is downloading missing TeX packages from the public TeX bundle, and only when you click Download and compile.
