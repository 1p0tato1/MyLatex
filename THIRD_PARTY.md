# Third-party software

MyLatex bundles or builds on the following open-source projects.

| Project | Use | License |
|---|---|---|
| [Tectonic](https://tectonic-typesetting.github.io) | LaTeX engine (bundled binary + TeX file cache) | MIT |
| [Tauri](https://tauri.app) | App shell | MIT / Apache-2.0 |
| [CodeMirror 6](https://codemirror.net) | Code editor | MIT |
| [pdf.js](https://mozilla.github.io/pdf.js/) | PDF rendering | Apache-2.0 |
| [KaTeX](https://katex.org) | Math in Visual mode | MIT |
| [JetBrains Mono](https://www.jetbrains.com/lp/mono/) | Editor font | OFL-1.1 |
| [Inter](https://rsms.me/inter/) | UI font | OFL-1.1 |
| [wordlist-english](https://github.com/words/wordlist-english) (SCOWL, © Kevin Atkinson) | English dictionary source | MIT / SCOWL |
| [an-array-of-french-words](https://github.com/words/an-array-of-french-words) | French dictionary source | MIT |

The TeX files in the bundled cache come from the TeX Live distribution through Tectonic's bundle; each package keeps its own license (LPPL, etc.).
MyLatex is not affiliated with JetBrains, Overleaf, ICML, NeurIPS or IEEE. The ICML/NeurIPS/IEEE templates are look-alikes, not the official style files.
